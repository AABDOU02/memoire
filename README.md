# Mémoire de Fin d'Études : Écotourisme et Conservation de l'Archipel de Zembra et Zembretta

Ce dépôt contient le code source du site web interactif de présentation pour le mémoire académique sur le **Parc National de Zembra et Zembretta** (Tunisie).

## 🌅 Aperçu du Projet
Le site est conçu avec un design méditerranéen haut de gamme et épuré (blanc plâtre, bleu azur, terre cuite, vert olive) mettant en valeur :
- La géographie et le climat de l'archipel.
- L'histoire et la succession des civilisations (chronologie interactive).
- La biodiversité exceptionnelle (flore endémique, faune terrestre, avifaune, milieu marin).
- Les activités d'écotourisme durable.
- Des documentaires vidéo et une galerie photo de 39 clichés.
- Les enjeux de préservation et les gardiens du parc (comme le berger Abdallah "Asfour").

## 🛠️ Technologies Utilisées
- HTML5 sémantique.
- CSS3 moderne et réactif (Vanilla CSS).
- JavaScript ES6+ (Intégration d'onglets, lightbox, animations au défilement).
- Déploiement automatisé via GitHub Pages.

## 🚀 Déploiement
Le site est automatiquement déployé sur **GitHub Pages** à chaque mise à jour de la branche `main` grâce au workflow GitHub Actions inclus.
